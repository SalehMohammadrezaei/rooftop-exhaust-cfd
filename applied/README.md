# Applied case

`case_by_hand/` is the template every applied run is generated from: the hand-built 0-degree,
10 m/s case whose every file is explained in the study notebook (Part E). Its dictionaries
(`system/`, `0.orig/`, `constant/` apart from meshes and surfaces) are the parts under version
control; the STL set is regenerated by `geometry/make_hall.py`, the mesh by the run driver.

What the template fixes: the domain (x −160 to 340 m, y ±188 m, z 0 to 136 m, 4 m background
cells), the refinement regions (ground layer, wake box, near box, building box, plant box,
chiller discharge, flue jets and pipes), the boundary conditions (log-law ABL inlet, fixed flows
at every opening, atmospheric wall functions on the ground, slip sides, fixed shear at the top),
the numerics (SIMPLE, linearUpwind for momentum, limitedLinear for turbulence, GAMG for pressure)
and the monitors (probes, forces, flow sums, receptor averages).

What `workflow/make_applied_case.py` changes per run: the rotation of the building and its
refinement boxes, the reference speed and the derived inlet quantities, the flue tip height, the
probe positions and the case record.
